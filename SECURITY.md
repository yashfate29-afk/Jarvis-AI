# Security Policy

## Supported Versions

The latest version of this project receives security updates.

| Version | Supported |
| ------- | --------- |
| Latest  | ✅ Yes |
| Older versions | ❌ No |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please do **not** create a public GitHub issue.

Instead, contact the maintainer privately.

When reporting a vulnerability, please include:

- A description of the issue
- Steps to reproduce
- The affected files or components
- Any proof-of-concept (if applicable)

I will investigate the report and work to provide a fix as soon as possible.

## Security Best Practices

- Never commit `.env` or `.env.local` files.
- Never commit API keys, access tokens, or secrets.
- Keep your dependencies up to date.
- Review code before merging changes.
- Use strong, unique credentials for any external services.
